## 3. Manual review of the diff

- No ROM address, no instruction listing; `tests/irqchain.s` states its wrapper as an authored JMP; test glyphs and
  menu structures stated as authored; no `docs/analysis/` page; the public-repo check finds nothing.
- `tests/textcompose.s` carries a timing figure of the original ROM in a comment ("original ROM: about nine"): a
  measurement, acceptable, but it belongs in an analysis page.
- The PR's audit page ends with "one original ROM version cannot represent all historical leaked sources": the
  provenance comment asks explicitly that no leaked Commodore source was consulted.

Correctness remarks for the contributor (not clean-room issues):
1. **Blocker as submitted, fixed on main since:** with `AddIntServer` treating any non-zero `iv_Data` as a chain,
   `AddIntServer(INTB_EXTER, …)` enqueued into the ciab.resource base, because our EXTER was an exclusive vector
   whose `iv_Data` held that base. Main now makes EXTER a server chain with ciab.resource at priority 0, as on 1.3
   (custom-chips §3.3; `tests/explvo_probe.sh` "EXP INT6"), so the PR's rule becomes safe once rebased.
   `RemIntServer` still tests `iv_Code` = the chain walker: with a wrapped `iv_Code`, an emptied chain keeps its
   INTENA bit (minor).
2. More CHIP RAM: layer backups (`lr_allocbm`) and Text's line buffer try MEMF_CHIP first (the line buffer is
   allocated and freed at every Text without a TmpRas: fragmentation), the menu bar layer goes from SIMPLE to
   SMART, cached menu surfaces stay in CHIP while a menu is held. 512 KB CHIP titles (Bubble Bobble, Lemmings) must
   be rechecked.
3. `bb_copy` routes every disjoint `$C0` BltBitMap through BltBitMapRastPort with a temporary RastPort: clipping now
   applies (BltBitMap has none on 1.3) and the stack grows by about 1 KB along BltBitMap → `br_copy` →
   `br_templatecopy` → BltTemplate (the input task has 4 KB); `br_templatecopy` checks TypeOfMem at each plane's
   start only, where #36's `br_blit` checks both ends.
4. `menus.s` `.sf_text` relies on SetFont preserving A1 before TextLength (true today, fragile under SetFunction); a
   NULL IText reaches `mn_strlen(0)`.
5. The cache key compare (up to 16 KB, mostly the font's CharData) runs at every menu box opening.
6. Conflicts with #36 (see `pr-36.md`) and with #37 (`Makefile`, `docs/PLAN.md`); the PR's own full-game runs used
   a ROM combining #36, #37 and #38, not this PR alone.
